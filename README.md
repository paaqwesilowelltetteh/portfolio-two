## 💻 Developer Commands

### Install Dependencies
```bash
pnpm install
# or:
npm install
```

### Start Development Server
```bash
pnpm dev
# or:
npm run dev
```

### Run TypeScript Verification
```bash
npm run typecheck
```

### Production Build
```bash
npm run build
```

### Static Generation (SSG)
```bash
npm run generate
```
